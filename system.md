## 1. ЧТО ЭТО ЗА СИСТЕМА

Ежедневный разбор валютного рынка по методу из мастер-промта
FINANCIAL WORLD MODEL AI. Суть метода: идти от состояния мира к цене, а не
наоборот. Сначала состояние каждой валюты, потом их столкновение, потом
позиционирование участников, и только в конце — уровни и вероятности.

Система построена в сентябре 2026 года за несколько дней. Это рабочий
прототип восприятия для большого проекта Financial World Intelligence (FWI),
техпроект которого лежит отдельно у владельца.

Инструменты: EURUSD, GBPUSD, USDJPY, USDCHF, AUDUSD, NZDUSD, USDCAD, XAUUSD,
BTCUSD. Индекса доллара в пакете нет: на AMarkets он называется не `DXY`,
настоящее имя символа не выяснено.

## 2. ЧТО ВЫДАВАТЬ ВЛАДЕЛЬЦУ

Формат отчёта утверждён 14.09.2026 и без его слова не меняется. Главный
результат — таблица трёх сценариев:

| Инструмент | Цена | ↑ | ↓ | ⟷ | Отмена ↑ (ниже) | Отмена ↓ (выше) | Отмена ⟷ (вне) |

Три вероятности в сумме дают 100. Горизонт — неделя. Флет = цена в пределах
одного дневного ATR. Отмена срабатывает ТОЛЬКО по закрытию свечи H4 за уровнем
и необратима. Полное описание правил — в разделе «Как разбирать этот пакет»
внутри самого пакета.

С 20.09 рядом с моими вероятностями идёт колонка «алгоритм» — вердикт порта
индикатора WaveMarkup_Auto из пакета. Это эксперимент: копим сравнение, даёт ли
мой слой фундамента и позиционирования что-то сверх чистой геометрии.
Разворотные вердикты алгоритма против тренда (со звёздочкой) без подтверждения
не принимаются — правило П-12 в журнале.

Плюс к таблице: головной вывод, закрытие прогнозов со сроком, короткие блоки
по инструментам, календарь, таблица «что дал каждый из девяти шагов», файл
журнала — в том же ответе, не отдельным сообщением.

## 3. ЖЕЛЕЗО И ФАЙЛЫ

**Сервер:** Windows, Timeweb, Москва, IP российский. Заходит владелец по RDP,
пользователь Administrator. Приглашение в консоли `PS C:\Users\Administrator`.
Если видишь `PS C:\Users\user` и русский интерфейс — это его домашний
компьютер, там ничего нет.

**Python:** `C:\Cerberus\venv\Scripts\python.exe` (общий с торговым проектом
ЦЕРБЕР, там уже стоят MetaTrader5, pandas, certifi).

**Папка системы:** `C:\FXReport\`

| Файл | Что делает |
|---|---|
| `fx_report.py` | тянет бары из MT5, считает свинги, подволны, ATR, стохастик, фибо |
| `market_context.py` | тянет COT с www.cftc.gov и ставки/волатильность с FRED |
| `run_daily.ps1` | запускает оба, склеивает пакет, зовёт выгрузку |
| `publish.ps1` | выгружает пакет на GitHub через Contents API |
| `analysis_spec.md` | описание метода, едет внутри пакета |
| `journal.md` | журнал тезисов, прогнозов и ошибок, едет внутри пакета |
| `system.md` | этот файл |
| `WaveMarkup_Auto.mq4` | индикатор разметки для MT4 владельца (`MQL4\Indicators`, компиляция F7); его логика перенесена в `fx_report.py` как «вердикт алгоритма» |
| `publish.json` | настройки GitHub: owner, repo, branch, path |
| `gh_token.txt` | токен GitHub, в чат НИКОГДА не присылать |
| `out\` | результаты: latest.md, context.md, daily.md, архив, лог |
| `cache\` | годовые архивы CFTC, перекачиваются не чаще раза в 20 часов |

**Расписание:** задача `FXReportDaily`, каждые 30 минут, старт в 00:05,

## 5. ГРАБЛИ, НА КОТОРЫЕ УЖЕ НАСТУПАЛИ

**Кодировка PowerShell.** Windows PowerShell 5.1 читает `.ps1` без BOM как
ANSI. Любая кириллица в скрипте ломает разбор. Все `.ps1` пишутся только
латиницей и сохраняются с BOM и переводами строк CRLF. Русский текст живёт
в `.md`-файлах.

**Кодировка вывода.** `tasklist` на русской Windows отдаёт cp866. Декодировать
через latin-1 с errors=ignore, иначе падает.

**Российский IP.** `publicreporting.cftc.gov` отдаёт 403. При этом
`www.cftc.gov` и FRED открыты — поэтому COT берётся годовыми архивами
с основного сайта, а не через API.

**Сертификаты.** Хранилище Windows не содержит части корневых сертификатов;
используется набор из certifi. Есть аварийный ключ `FXCTX_INSECURE=1`.

**Кэш чтения.** Любой адрес внутри одного чата читается один раз; повтор даёт
старый результат. Отсюда схема с датированной ссылкой из лога (раздел 0).

**Серверные правки.** 20.09 я выдал полный `fx_report.py` из своей копии, где не
было правки владельца с `DXY`, — файл лёг поверх, DXY из пакета пропал. Правило:
если владелец что-то правил на сервере командой, эта правка должна попасть в мою
копию до того, как я выдам полный файл. Сомневаешься — попроси показать строку.

**Обрезка пакета.** До 28.09 вердикты и COT стояли в хвосте и терялись при
чтении. Порядок исправлен (раздел 0, п. 4).

**Пункт у крипты.** У BTC на AMarkets ноль знаков; пункт отчёта = 1 доллар.

**Терминал MT5.** Скрипт НИКОГДА не запускает терминал сам: `mt5.initialize()`
поднимает его, а это уже приводило к аварии с дублями. Перед подключением
проверяется наличие процесса terminal64.exe; если его нет — выход с
сообщением. Ордера не выставляются, чужие процессы не трогаются.

**Полные пути.** Команды владельцу давать только с полными путями: он
запускает их из разных папок и с разных машин.

Договорённость: когда наберётся около двадцати независимых эпизодов, считаем
калибровку по-настоящему. Если направленные оценки окажутся хуже монетки —
не «переворачивать» их, а перестать выдавать и оставить описание состояния
рынка и уровни.

Не обещать доходность. Не изображать уверенность, которой нет.
